# NoSQL DBMS CVE Risk Project
A Python desktop application built with CustomTkinter that collects Common Vulnerabilities and Exposures (CVE) data from the NVD API v2.0 and calculates comparative risk scores.

# System Requirements:
Operating System: Windows 11 (verified)
Python: Python 3.10+
Database: MySQL Community Server (running locally on default port'3306')
  Download: https://dev.mysql.com/downloads/installer/

# How to Start the Program:
1. Download the GitHub repository ZIP file and extract it
2. In the extracted folder, enter "cmd" in the File Explorer address bar, or navigate to the files in Command Prompt.
3. Install requirements: "pip install -r requirements.txt"
4. Then run the Main.py file: "python3 main.py"
5. The DBMS Vulnerability Dashboard (CustomTkinter GUI) will open in a separate window.
6. The placeholder password to connect to the Database is "password"
